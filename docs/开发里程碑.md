# 开发里程碑

项目优先服务实习求职；第一个可投递版本先于大规模功能扩展。

| 阶段 | 可检查的交付 |
| --- | --- |
| V0：工程骨架 | 前后端启动、项目/资料/反馈/工单持久化、基础接口测试 |
| V1：可投递演示 | AI API 接入、资料检索与引用、分析执行记录、人工审批后建立工单、录屏 |
| V2：可靠性 | 项目隔离、无依据拒答、模型/工具错误、幂等审批、固定测试集与 Bad Case 记录 |
| V3：真实使用 | 小程序试用者反馈、脱敏记录、时间测量、根据反馈改进 UI 与工作流 |
| V4：求职材料 | 在线或本地演示、代码、README、测试报告、简历项目条目与面试讲解 |

严格按真实完成状态更新，不把计划写成业绩。毕业设计所需的文献综述与论文形式在求职版本稳定后补充。
