## 下轮待验证修改

1. 提示词要求只回答当前问题；人数工具通过只代表人数规则通过，名称等其他条件须单独核对。
2. 禁止模型声称已完成未执行的转交、通知、调查，也不从无后端等架构事实推断收入等未知业务数据。
3. 引用只保留直接支持核心答案的原文；将“引用相关性”单列人工评审。
4. 对提供方短暂错误做有限重试，Trace 记录不含密钥和响应正文的安全错误代码；对校验失败区分缺字段、缺引用和非法引用。

修改后先复测上述失败题与无答案题，再按需运行完整固定集。真实试用者反馈需另行获取、脱敏并标注来源。
