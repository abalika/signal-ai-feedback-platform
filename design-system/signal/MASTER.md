# Signal 工作台设计规范

面向 AI 用户反馈与技术工单平台的浅色业务界面。基于 ui-ux-pro-max 的 Minimalism & Swiss Style 方向调整，强调清晰的信息层级、真实数据和可追溯的人工审核。

## 视觉基础

| 语义 | 值 | 用途 |
| --- | --- | --- |
| 主文字 | `#24342e` | 标题、指标、正文 |
| 次级文字 | `#5c6d60` | 说明、元信息 |
| 强调色 | `#287453` | 主操作、选中状态、焦点 |
| 强调悬停 | `#1c5b3f` | 主按钮悬停 |
| 强调浅底 | `#edf5ef` | 导航选中、辅助操作 |
| 工作区 | `#f6f8f7` | 页面底色 |
| 卡片 | `#ffffff` | 业务内容、表格、弹窗 |
| 分割线 | `#e6ebe7` | 卡片与区块边界 |
| 评测封面 | `#254b3a` | 评测报告主视觉 |

字体优先 Segoe UI / PingFang SC / Microsoft YaHei；数字使用等宽数字特性，英文眉题使用 Consolas。页面标题 25–32px，区块标题 17–18px，主要正文 14px，辅助信息 11–13px。避免依赖在线字体。

统一使用 24px viewBox 的细线 SVG 图标。卡片圆角 16px、按钮与输入框 8px；主要间距按 8 / 16 / 24 / 32px 层级组织，具体密度随工作台内容调整。

## 布局与交互

- 桌面：236px 固定侧栏，主内容最大宽度 1510px，四列指标，双列业务面板。
- 1000px 以下：指标两列、主要面板单列。
- 800px 以下：项目切换与五个导航入口移入页面顶部，隐藏侧栏。
- 500px 以下：报告封面纵向排列，列表行允许换行，表格保留可滚动容器。
- 手机主要操作至少 44px 高，表单输入字号 16px；键盘焦点使用明确的绿色外框。
- 弹窗使用原生 dialog，隔离背景焦点，支持 Escape、关闭按钮和关闭后的焦点恢复。
- 评测页签支持左右方向键、Home、End；筛选按钮通过 aria-pressed 表达状态。
- 所有页面保留加载、空数据、搜索无结果、错误和禁用状态；减少动态效果时关闭非必要动画。

## 页面职责

1. **工作台总览**：当前项目实际反馈、工单、资料、运行指标和处理进度。
2. **反馈收件箱**：搜索原文与来源，查看 AI 建议、引用、人工审核及执行记录。
3. **技术工单**：沿用已审核工单和解决记录。
4. **产品资料库**：项目资料与引用来源。
5. **评测中心**：历史报告与固定题集的可查看界面，为后续回归功能预留结构。

## 数据表达约束

评测页面直接读取仓库的三份历史 JSON：固定题集、2026-09-16 汇总、检索对比。36 条固定题包含 30 条可回答题与 6 条无答案题，检索集是其中 30 条的子集。历史人工核对项不能表述为生产准确率。

未采集的费用、延迟以破折号和说明呈现；四类失败诊断标为待接入，不生成虚假统计。导出只保存已有历史报告。界面访问、筛选、查看详情不会触发新的模型调用。
